# Calibrate with the ENS Corpus

## Recover the legal frontier

1. Complete the repository cold start required by `AGENTS.md` and preserve unrelated worktree changes.
2. Read the production Skill for the requested artifact. Read `00_Project/PROJECT_SPEC.md`, the target Module Map, the canonical Cours, and the Exam P boundary when they govern the request.
3. Treat those files as authority for scope and mathematics. Treat the ENS corpus only as evidence about architecture, responsibility, morphology, density, and level.
4. Read [calibration-protocol.md](references/calibration-protocol.md) before selecting sources or drafting the brief.

Do not use corpus prestige to legalize a theorem, prerequisite, or module extension that the canonical frontier excludes.

## Select the minimum source set

1. Read `00_Project/Bibliography.md` and `99_Sources/ENS/INDEX.md`.
2. Read exactly one relevant child index when the root index routes to an extended collection.
3. Select at most three source units by default:
   - one theory source for theorem or representation architecture;
   - one exercise-and-correction source for problem and Corrige morphology;
   - optionally, one cross-campus source or annale for independent level or timing calibration.
4. Treat one PDF, or one inseparable statement-and-correction pair, as one source unit.
5. Exceed three units only for an explicitly authorized full-course or cross-module audit, and state why each extra unit changes the conclusion.

Open only the selected PDFs. Do not scan the corpus tree, recreate its inventory, or copy index metadata into this Skill.

## Produce an ephemeral calibration brief

Create the brief in the current turn before production. Include every field below:

- `artifact`, `regime`, and `legal cours frontier`;
- each exact local source, institution, academic year, document role, and reason for selection;
- portable features: theorem architecture, student responsibility, dependency chain, structural pathology, indication density, and Corrige density;
- rejected imports: beyond-frontier material, surface style, and source-specific notation;
- concrete additions, removals, or responsibility shifts for the requested artifact;
- one attribution type for each source relationship: `adapted`, `combined`, `inspired`, or `independently reconstructed`.

Keep the brief in turn context unless the user explicitly requests a persistent dossier. For every selected unit, make it possible to recover: why this source, what it calibrates, and what must not be imported.

## Hand the brief to production

- Give canonical Cours and theorem-note work to `$write-ens-math-notes` after calibration.
- Give full TD, Corrige, DM, and assessment work to `$write-ens-td` after calibration.
- Give a daily unfamiliar transfer or exit to `$build-daily-offline-study-packet` only when canonical tasks do not already supply it.
- Use the brief directly for Module Map or course-route planning, but let the canonical project files decide scope, status, and dependencies.

Do not write the requested mathematical artifact as a substitute for the appropriate production Skill. Continue in the same turn with that Skill and the calibrated brief.

## Preserve provenance and authority

For direct adaptation or combination, place a portable attribution in the artifact that gives the exact PDF, printed exercise number, and adaptation type. If the source has no printed exercise number, give an equally exact printed heading and PDF page; otherwise do not adapt it directly.

For calibration-only use, report the selected sources in the delivery summary without cluttering the artifact. Never list an ENS PDF as a Study Log `canonical-source`, and never treat corpus use or generated work as mastery evidence.

## Verify the calibration

Before production, confirm that:

- removing ENS names, French headings, and institutional layout leaves the same mathematical responsibility;
- difficulty comes from representation, construction, hypothesis control, transfer, or failure analysis rather than missing data or obscure tricks;
- every imported dependency is legal at the cours frontier;
- every direct adaptation has exact provenance;
- no source has been mistaken for project canonical authority.
