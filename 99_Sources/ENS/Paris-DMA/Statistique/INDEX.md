# Statistique — ENS Paris DMA / FIMFA

## Identity and provenance

- Level: FIMFA / ENS M1.
- Official course description: [Statistique](https://www.math.ens.psl.eu/formations/statistiques/).

The collection combines explicitly dated series. It does not treat exercises from 2007–2008, 2012–2013 and 2015–2016 as one edition.

## Intended use

Use these materials to preserve the statistical object before calculation: experiment, parameter, domination, likelihood, estimator or test, loss and risk. They calibrate model legitimacy and proof responsibility, not merely computational difficulty. The handwritten 2008 correction is retained as a historical solution source and should not determine modern notation by itself.
